🔴 Hotspot Debug 面板

先點開 1F / 2F / 3F / 4-15F / RF 平面圖後，於燈箱中拖曳紅點調整位置；
矩形熱點可整塊拖曳移動、右下角紅色手把調整大小。
4-15F 圖面另有藍色虛線「列印卡片」（各戶面積 / 基本資料），拖曳即可調整列印時的位置。
4-15F 瀏覽模式「坪數卡」可直接拖曳移動；「基本資料開啟鈕」拖曳可上下調整位置（非 Debug 時點按＝開啟中央燈箱）。
檢視：滾輪縮放；按住「空白鍵」（或 Alt / 滑鼠中鍵）再拖曳可平移畫面，即使壓在熱點或卡片上也優先平移。
列印底圖（4-15F）：Ctrl+滾輪 = 縮放底圖、Ctrl+拖曳 = 移動底圖、Ctrl+雙擊 = 重設，縮小底圖可避免資訊卡遮到圖面，列印會套用相同設定。
建議改用上方「🖨️ A3 列印排版檢視器」：以真實 A3 橫式紙面（含表頭）排版底圖與卡片，所見即所得。
標題列可拖曳移動面板、⇄ 快速換邊、— 收合。
連按 5 次 D 鍵或 ESC 可關閉本面板。
