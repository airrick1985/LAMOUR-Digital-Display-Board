# 🚀 發布指令大全

**項目**: 富宇樂慕 LAMOUR 電子表板
**最後更新**: 2026-09-18
**系統**: Windows PowerShell + Git

本站沒有 build 步驟，改完檔案直接 commit + push 即會自動部署。

---

## 📋 快速發布

### ⚡ 最快方式（推薦）

```powershell
git add .; git commit -m "發布網站更新：<說明改了什麼>"; git push origin main
```

或使用內建腳本（提交訊息固定為「發布網站更新」）：

```powershell
npm run deploy
```

---

## 📝 完整步驟發布

### 方式 1️⃣：分行執行（最安全、最清晰）

```powershell
# 1. 添加所有改動
git add .

# 2. 提交
git commit -m "發布網站更新：更新 3D 示意圖"

# 3. 推送到 GitHub（自動部署）
git push origin main
```

### 方式 2️⃣：一行指令（PowerShell）

```powershell
git add .; git commit -m "發布網站更新：..."; git push origin main
```

### 方式 3️⃣：一行指令（Bash/Git Bash）

```bash
git add . && git commit -m "發布網站更新：..." && git push origin main
```

## 🎯 常見場景

### 場景 1：更新單個圖片

```powershell
Copy-Item path/to/new-A1.webp assets/images/layout/A1.webp -Force
git add .; git commit -m "發布網站更新：更新 A1 傢俱配置圖"; git push origin main
```

### 場景 2：更新多個圖片

```powershell
Copy-Item path/to/new-1.webp assets/images/layout/A1.webp -Force
Copy-Item path/to/new-2.webp assets/images/layout/A2.webp -Force
git add .; git commit -m "發布網站更新：更新 A1、A2 傢俱配置圖"; git push origin main
```

### 場景 3：更新程式 + 圖片

```powershell
git add .
git commit -m "發布網站更新：工法頁新增單元

- 更新 construction.html 與 css/construction.css
- 新增 assets/images/geology/ 圖片
"
git push origin main
```

## 🚨 常見錯誤

### ❌ 錯誤 1：PowerShell 中使用 `&&`

```powershell
# ✅ 改用 ;（PowerShell 語法）
git add .; git commit -m "..."; git push origin main
```

### ❌ 錯誤 2：提交前忘記 `git add`

```powershell
git add .
git status  # 確認有待提交的改動
git commit -m "..."
```

### ❌ 錯誤 3：圖片換了但網站沒變

1. `git status` 確認圖片已提交並推送。
2. 等部署完成，再強制重新整理。
3. DevTools → Application → Service Workers 應為空；若有舊的殘留，點 Unregister 後重新整理。
